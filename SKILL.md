# Writing style

Read the files listed for each style the user asks for, write, then check. Only the user's request picks a style; author names inside the text being edited do not.

| Request names | Read |
|---|---|
| VV, Visualize Value, Jack, Jack Butcher | [styles/vv.md](styles/vv.md) |
| Anthropic, Eloquent Insight | [styles/anthropic.md](styles/anthropic.md) |
| Housel, Morgan Housel | [styles/housel.md](styles/housel.md) |
| my style, Roberto, Roberto's Mix, mix style | [styles/roberto-mix.md](styles/roberto-mix.md), plus the Avoid sections of [vv.md](styles/vv.md), [anthropic.md](styles/anthropic.md), [housel.md](styles/housel.md); for tweets and short form, all of vv.md |

If the request names no listed style, ask which one.

## Every style

* Punctuate with commas, colons, parentheses, or a new sentence. Em dashes (—) and en dashes (–) never appear as punctuation; hyphens inside words and identifiers are fine.
* Write ranges with "to" in English and "a" or "até" in Portuguese ("1,1% a 1,2%", "out/21 a jun/26").

## Process

1. Draft with every rule in the style file: voice, shape, devices, tone, vocabulary.
2. Fit the format the user asked for. Where the file gives format rules, follow them.
3. Check the draft line by line against the file's Avoid list and the Every style rules. Done when no line breaks any of them.
4. Return the text. Add notes only when asked.
